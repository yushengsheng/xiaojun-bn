Linux 版本只加载交易所模块，共用桌面版交易、签名、限流、停止清理和订单恢复代码，不启动链上页面或图形桌面。

首次安装请使用主 README 的一键安装命令，支持 Ubuntu 24.04、Debian 12/13 x86_64。下载的安装器绑定具体版本，校验发行包 SHA-256 及每个文件；代理内核同时校验归档和可执行文件哈希。已有安装、配置或端口冲突会在安装前拒绝。安装器不承担正在运行的交易服务器升级。

新安装使用独立 `xiaojun-exchange-nginx.service` 和完整配置，不修改或重启原有 nginx、代理及其他服务。自动 IP / 域名证书需要空闲且公网可达的 TCP 80；若已被其他服务使用，保留原服务，提供匹配管理地址的自备完整证书和私钥。自备证书由原工具续期，复制到本项目证书路径后重新加载本项目 nginx。面板端口和内部端口均可自定义。

浏览器打开服务器 HTTPS 面板即可设置账号、策略和代理，选择参与账号并执行现货各模式、合约、理财、股票、查询、BNB 归集、提现和失败重跑。单个账号可独立执行 / 停止；账号凭据可添加、编辑、导入、删除、导出和销毁。所有资金操作仍受交易所 API 权限和规则限制。

网页沿用桌面交易所页面的浅色布局、三行共享策略、当前 API 控制、账号表格、两行批量按钮及运行 / 报错日志。账号支持双击勾选、右键菜单、完整 API Key / 地址复制及循环定位搜索；支持剪贴板、列表 Ctrl+V / Cmd+V 和 UTF-8 / GB18030 文件导入，复用桌面解析规则，重复 API 跳过且不覆盖凭据。执行、批量提现、归集、赎回、重试和删除显示对应确认；执行窗口的自动提现 / 预买 BNB 仅对本次生效。查询及停止不增加确认。浏览器拒绝剪贴板读取时使用粘贴输入框。服务器敏感导出等操作继续保留密码验证。

首次设置需要服务器初始化码，密码至少 8 位，可与本地相同。密码通过 HTTPS 传入执行进程，复用现有 scrypt + AES-GCM 程序锁和认证配置格式。API Key / Secret、代理凭据及恢复记录在独立目录加密保存。网页会话使用 Secure / HttpOnly / SameSite Cookie，写请求校验 Origin 和 CSRF，密码尝试限速；导出凭据、销毁账号、锁定或改密须再次验证密码。密码和凭据不写入 URL、网页存储或访问日志。

执行进程与网页进程独立。电脑关机、浏览器退出、网页进程重启均不停止任务。执行进程或服务器重启后必须重新解锁，不自动继续轮次或重新提交资金操作；上次中断会显示在面板，后续执行复用现有订单核对机制。停止状态需等撤单 / 清理确认后才能开始新任务。网络或服务器故障时无法承诺即时撤单。

运行中的普通设置保存用于下次任务，自动分仓判断参数可热更新。不要让本地和 Linux 同时操作同一账号的同一资金池；部署不会迁移本地凭据、启动交易或改变本地正在运行的程序。

服务器目录：

- `/opt/xiaojun-exchange/current`：只读源码，独立 `venv` 和 `certbot-venv`。
- `/var/lib/xiaojun-exchange`：专用用户所有的加密配置 / 运行数据，0700；Worker socket 为 0600。
- `/etc/xiaojun-exchange`：管理地址、反向代理和独立证书配置。
- 面板 TCP 26483；后端仅监听 127.0.0.1:18880。TCP 80 只响应证书验证路径，其余 404，不跳转面板。

systemd 管理 worker / web，执行进程默认 4 个并发账号。Worker 内存软限制 450 MiB、硬限制 650 MiB；Web 为 100 / 180 MiB；失效重启后 worker 锁定等待密码。硬内存限制可导致执行进程退出，因此大量并发应先调低并发再观察资源。新服务使用较低 CPU 权重，独立账号、目录、端口和日志，不修改现有代理服务。

每小时自动清理旧进程日志和超过 7 天的下载临时目录，清理超过 24 小时的中断原子写临时文件。运行日志滚动保留最多 3 × 5 MiB，兼容日志最多 2 × 2 MiB，旧进程日志额外保留最多 20 MiB / 7 天；页面和内存日志队列都有容量上限。资产 / 提现文本分别保留当前及最近 3 份，每份约 5 MiB。账号、主配置、备份、代理二进制及未完成订单恢复账本不按时间删除；原有订单账本只压缩可删除的已结束历史。远程操作编号保留 7 天，过期请求拒绝执行，因此清理后重放不会下单。

每分钟检查磁盘。可用空间少于 512 MiB 或 2% 时面板告警并拒绝新任务，仍允许停止 / 清理；不自动中断正在运行的交易。独立清理 timer 在锁定状态仍可运行。nginx / ACME 日志由 logrotate 限额管理。公网 IP 证书约 6 天有效，每 12 小时检查续期并自动重新加载 nginx；80 端口须保持可达。没有域名或付费附加服务的要求。

回归入口仍为 `python3 tools/run_full_regression.py`；包含服务器隔离集成测试、桌面 GUI / 链上自检及依赖审计。服务器额外运行 Linux 测试与实际 HTTPS / 启停 / timer / 证书续期检查。资金操作使用模拟交易所客户端验证；部署验收不使用真实账号下单。
